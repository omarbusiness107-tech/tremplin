Bestiary

What lives down there, and what this is

Every sprite here is drawn in code, pixel by pixel — there are no image files. The rules come from a terminal roguelike written in Python: the same room generation, the same field of view, the same combat arithmetic and balance figures.

Seeds do not match the terminal build, which draws from Python's random number generator. Your run is kept in this browser only; saving suspends a run, loading consumes the save, and dying deletes it.
