About this port

Ember Depths in the browser

This is a browser port of a terminal roguelike written in Python with Textual. The rules are carried over faithfully — the same room generation, the same combat arithmetic, the same monsters, items and balance figures.

Seeds do not match between the two. The terminal build draws from Python's random number generator and this one cannot reproduce it, so the same seed number builds a different dungeon here.

Your run is kept in this browser only. Saving suspends a run; loading it consumes the save, and dying deletes it. A run can be put down and picked up, never rewound.
